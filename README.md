# Narragansett Bay hypoxia forecasting

Using machine learning to forecast hypoxia (low dissolved oxygen) in Narragansett Bay,
from the Fixed-Site Monitoring Network's multi-station sonde record.

Full writeup: [Narragansett Bay hypoxia forecasting](https://drive.google.com/file/d/1i0EluB80M1lAwUiWJL_dn9eNIYpdUYhO/view)

## About the data and the figures in these notebooks

The real Fixed-Site Monitoring Network data is owned by RI DEM, the Narragansett Bay
Commission and URI GSO, and is not mine to redistribute. As such, while these models were developed against that data (which was graciously provided when I reached out), the data itself is not publicized here. Instead, synthetic data was used to compute plots, SHAP charts, etc...

Please reach out with any questions, and thank you to the DEM, NBC, and URI GSO!!
